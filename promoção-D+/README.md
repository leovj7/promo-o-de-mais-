# ProdPreço — estrutura separada

## Estrutura
- `index.html` — Home
- `pages/produtos.html` — catálogo de produtos
- `pages/sobre.html` — apresentação do projeto
- `pages/contato.html` — formulário de contato
- `css/style.css` — CSS original + camada responsiva
- `js/app.js` — produtos, busca, filtros, modal e links de afiliados
- `assets/images/` — imagens dos produtos

## Funcionalidades
- Menu desktop e menu mobile.
- Busca por nome, categoria, descrição, badge, prós e contras.
- Busca por categoria na barra: por exemplo, `tecnologia` ou `Casa & Cozinha`.
- Filtros por categoria.
- Modal de análise completa.
- Botão de afiliado preparado para receber links reais.
- Navegação Home / Produtos / Sobre / Contato.
- Rodapé com affiliate disclosure em inglês.

## Links de afiliado
No arquivo `js/app.js`, substitua cada:
`affiliateLink: "#"`
pelo link real fornecido pela plataforma de afiliados.

## Observação
Os produtos e preços presentes no projeto são dados de demonstração do código original. Antes de publicar, substitua-os por informações reais e atualizadas.
